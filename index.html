Hear the trigger

          
Translate story language into an invariant. The point is not to memorize a solution; it is to recognize the smallest data structure that keeps the needed fact current.

        

        

          
Monotonic stack
“For each item, find the nearest greater/smaller to its left/right.”
Store indices. Pop while the current value resolves the stack top. For circular input, scan 2n positions with modulo.
while stack and a[i] > a[stack[-1]]

          
Sliding window
“Longest/shortest substring or subarray satisfying…”
Expand right; shrink left while invalid. Track frequencies. Exactly K often equals atMost(K) − atMost(K−1).
expand → repair invariant → score

          
Binary search on answer
“Maximize the minimum,” “k pieces,” or a yes/no feasibility boundary.
Search the answer range, not the input. Write a monotone works(x) predicate and choose bounds carefully.
if works(mid): move toward better

          
Topological sort
Prerequisites, dependencies, valid ordering, “can all finish?”
Build adjacency and indegree; process zero-indegree nodes. Fewer than n processed means a cycle.
Kahn BFS or DFS 3-color

          
Union-find
Connectivity changes one update at a time; count components after each add.
Path compression + union by rank/size. Flatten a grid with r·C+c and adjust the component count incrementally.
new node: count++ · merged roots: count--

          
Intervals + heap
Minimum rooms/resources or maximum overlap over start/end times.
Clarify boundary semantics. Sort by start, release finished resources from a min-heap, then add the new end.
if minEnd <= start: reuse

          
Trie
Prefixes, autocomplete, dictionary traversal, prefix counts.
Each node has children and terminal state. On a board, backtrack while pruning paths that are not prefixes.
walk(prefix) then DFS descendants

          
Range structure
Both update(i, value) and query(l, r) must be fast.
Prefix sums make updates O(n). Fenwick is compact for sums; segment trees are more general and use roughly 4N space.
Fenwick: i += i & -i

          
Heap / top-K
Top K, kth largest, live stream, or merge sorted candidate lists.
Use a size-K min-heap for top-K largest; two balanced heaps for a running median; a frontier heap for k-way merge.
keep only what can still enter the answer

          
Backtracking → DP
Generate all valid partitions under local rules; then “count only.”
DFS over position and choices; prune immediately. Counting replaces returned lists with memoized state totals.
state = (position, piecesUsed)

          
Grid BFS / DFS
Connected regions, islands, shortest moves, spreading by minutes.
DFS counts components; BFS gives shortest unweighted distance. Start from all sources at once for spreading-time problems.
BFS state may include keys / masks

          
Stack parsing
Nested brackets, repetition syntax, expression evaluation.
Push context on an opener and combine on a closer. Be able to explain the equivalent recursive parser.
number + previousString on the stack

          
Mixed-radix counting
Find the nth item in a custom enumeration mixing alphabets.
Compute the size of each block, subtract whole blocks, then decode the remainder digit by digit.
block = 10^digits × 26^letters

          
Clarify first
A one-line prompt with missing rules or a real-world wrapper.
Ask about ranges, boundaries, sortedness, duplicates, invalid input, and output semantics before choosing a structure.
ambiguity is part of the interview
